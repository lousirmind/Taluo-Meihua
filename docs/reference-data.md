## 1.2 八字排盘规则

八字由四柱组成：年柱、月柱、日柱、时柱。每柱由一个天干和一个地支组成，共八个字。

### 1.2.1 年柱推算

**关键规则**：以**立春**为年柱分界，非正月初一。

**算法**：
1. 查找出生年份的立春日期
2. 如果出生日期在立春之前 → 年柱使用上一年的干支
3. 如果出生日期在立春当日及之后 → 年柱使用当年的干支

**年干支计算公式**：
```
year_gan_index = (year - 4) % 10   # 0=甲, 1=乙, ..., 9=癸
year_zhi_index = (year - 4) % 12   # 0=子, 1=丑, ..., 11=亥
```

**近百年立春公历日期参考**（精确计算需节气表）：
- 立春通常在公历 2月3日~5日

**示例**：
- 2000年2月4日20:32立春
  - 2000年2月4日19:00出生 → 年柱为己卯（1999年干支）
  - 2000年2月4日21:00出生 → 年柱为庚辰（2000年干支）

**月干推算——五虎遁口诀**：
```
甲己之年丙作首，乙庚之岁戊为头。
丙辛必定寻庚起，丁壬壬位顺行流。
若问戊癸何方发，甲寅之上好追求。
```

**五虎遁算法规则**：
1. 确定年天干
2. 根据年天干确定正月（寅月）的天干
3. 正月天干确定后，按十天干顺序顺排十二个月

**年干→正月（寅月）天干对照表**：

| 年干 | 正月(寅)天干 | 算法 |
|------|-------------|------|
| 甲、己 | 丙 | year_gan_index ∈ {0,5} → 寅月干=丙(index=2) |
| 乙、庚 | 戊 | year_gan_index ∈ {1,6} → 寅月干=戊(index=4) |
| 丙、辛 | 庚 | year_gan_index ∈ {2,7} → 寅月干=庚(index=6) |
| 丁、壬 | 壬 | year_gan_index ∈ {3,8} → 寅月干=壬(index=8) |
| 戊、癸 | 甲 | year_gan_index ∈ {4,9} → 寅月干=甲(index=0) |

**通用公式**：
```
寅月天干索引 = (year_gan_index % 5) * 2 + 2
# 即：(年干索引对5取余) * 2 + 2
# year_gan_index: 0=甲,1=乙,2=丙,3=丁,4=戊,5=己,6=庚,7=辛,8=壬,9=癸
```

**月干推算步骤**：
1. 确定出生时刻所在的月支（根据节气判断）
2. 使用五虎遁确定寅月天干
3. `月干索引 = (寅月天干索引 + 月支索引 - 2) % 10`
   - 月支索引：寅=0, 卯=1, ..., 丑=11
   - 寅月天干索引对应的月支索引是寅=0

### 1.2.3 日柱推算

**公历公式法（推荐用于编程实现）**：

日干支计算使用公历日期直接推算，使用一个已知的参考点进行偏移计算。

**方法一：1900年基准法**

1. 以 1900年1月1日（甲戌日）为基准
2. 计算目标日期与基准日之间的天数差
3. 日干支序号 = (天数差) mod 60，对应六十甲子表

```
# 伪代码
base_date = Date(1900, 1, 1)  # 甲戌日
base_gan_index = 0  # 甲
base_zhi_index = 10 # 戌

days_diff = (target_date - base_date).days
total_offset = days_diff
gan_index = (base_gan_index + total_offset) % 10
zhi_index = (base_zhi_index + total_offset) % 12
```

**方法二：2000年基准法（精度更高）**

以 2000年1月1日（戊午日）为基准：
- base_gan_index = 4（戊）
- base_zhi_index = 6（午）

**闰年判定**：
```
def is_leap_year(y):
    return (y % 4 == 0 and y % 100 != 0) or (y % 400 == 0)
```

**每月天数**：
```
month_days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
# 闰年2月为29天
```

## 1.3 十神系统

十神是以**日干**（日柱的天干，代表"我"）为中心，与其他三个天干及地支藏干之间的关系分类。

### 1.3.1 十神确定规则

以日干五行属性为"我"，与其他天干的生克关系确定十神：

**同我者**（五行相同）：
- 阴阳相同 → **比肩**（兄弟、朋友、同辈）
- 阴阳不同 → **劫财**（竞争者、合作伙伴）

**我生者**（我去生的五行）：
- 阴阳相同 → **食神**（才华、口福、子女）
- 阴阳不同 → **伤官**（聪明、叛逆、表现力）

**我克者**（我去克的五行）：
- 阴阳相同 → **偏财**（横财、父亲、意外之财）
- 阴阳不同 → **正财**（工资、妻子、稳定收入）

**克我者**（来克我的五行）：
- 阴阳相同 → **七杀/偏官**（压力、权威、挑战）
- 阴阳不同 → **正官**（官职、丈夫、纪律）

**生我者**（来生我的五行）：
- 阴阳相同 → **偏印/枭神**（继母、偏门学问）
- 阴阳不同 → **正印**（母亲、学业、贵人）

### 1.3.2 十神速查表

**以甲木日干为例**：

|----------|----------|------|

## 1.5 大运排法

大运是八字命理中推算一生运势起伏的系统，每十年一步大运。

### 1.5.1 阳年阴年判断

- **阳年**：年干为阳（甲、丙、戊、庚、壬）
- **阴年**：年干为阴（乙、丁、己、辛、癸）

### 1.5.2 顺逆排法规则

| 性别 | 年干阴阳 | 排法 |
|------|----------|------|
| 男 | 阳年 | 顺排（从月柱往后排） |
| 男 | 阴年 | 逆排（从月柱往前排） |
| 女 | 阳年 | 逆排（从月柱往前排） |
| 女 | 阴年 | 顺排（从月柱往后排） |

**顺排规则**：月柱的下一个干支为第一步大运，再下一个为第二步...
**逆排规则**：月柱的上一个干支为第一步大运，再上一个为第二步...

### 1.5.3 起运年龄计算

**顺排**：从出生日到下一个节气的天数 ÷ 3（三天为一年，一天为四个月，一个时辰为十天）

**逆排**：从出生日到上一个节气的天数 ÷ 3

**算法步骤**：
1. 确定大运是顺排还是逆排
2. 如果是顺排：计算从出生日到出生后**下一个节气**的天数
3. 如果是逆排：计算从出生日到出生前**上一个节气**的天数
4. `起运年龄 = 天数 ÷ 3`
5. 不足3天的按比例计算（1天=4个月，1个时辰=10天）

### 1.5.4 大运干支排列规则

- 每步大运管十年
- 大运干支从月柱顺推或逆推
- 第一步大运的干支由月柱决定

**干支顺推**：在当前干支基础上，天干地支各进一位
**干支逆推**：在当前干支基础上，天干地支各退一位

**完整推算步骤**：
1. 确定出生年干的阴阳
2. 确定命主性别
3. 判断排法（顺/逆）
4. 计算起运年龄
5. 从月柱开始，按顺/逆方向排出每一步大运

## 2.2 起卦方法

### 2.2.1 数字起卦法

**核心公式**：
```
上卦序号 = 第一个数 mod 8  （余0则为8，对应坤卦）
下卦序号 = 第二个数 mod 8  （余0则为8，对应坤卦）
动爻位置 = 第三个数 mod 6  （余0则为6，即第六爻动）
```

**示例**：用户输入数字 3, 5, 7
- 上卦：3 mod 8 = 3 → 离卦（☲）
- 下卦：5 mod 8 = 5 → 巽卦（☴）
- 动爻：7 mod 6 = 1 → 第一爻动
- 本卦：风火家人（䷤，上巽下离）
- 变卦：第一爻变动（阳变阴），下卦离变为艮 → 风山渐（䷴）

**多数字处理（超过3个数）**：
- 如有6个数字：前两个求和取上卦，中间两个求和取下卦，后两个求和取动爻
- 或将所有数字按顺序三个一组分组处理

### 2.2.2 时间起卦法

**公历时间起卦**：
1. 年月日相加为上卦基数：`上卦数 = (年 + 月 + 日) mod 8`
2. 年月日时相加为下卦基数：`下卦数 = (年 + 月 + 日 + 时) mod 8`
3. 年月日时相加为动爻基数：`动爻 = (年 + 月 + 日 + 时) mod 6`

**农历时间起卦**：
- 年数：取地支序数（子=1, 丑=2, ..., 亥=12）
- 月数：取农历月份（正月=1, 二月=2, ..., 十二月=12）
- 日数：取农历日期（初一=1, 初二=2, ..., 三十=30）
- 时数：取地支序数（子=1, 丑=2, ..., 亥=12）

```
上卦 = (年数 + 月数 + 日数) mod 8
下卦 = (年数 + 月数 + 日数 + 时数) mod 8
动爻 = (年数 + 月数 + 日数 + 时数) mod 6
```

**注意**：余数为0时，上卦/下卦取8（坤），动爻取6（上爻动）。

### 2.2.3 物数起卦法

- 以所见物品的数量起卦
- 如见三朵花：3为上卦=离，下卦=离（时间/或再取一数），本卦为离

### 2.3.1 本卦到互卦

**规则**：

- **上互卦**：取本卦的 **第三、四、五** 爻（3→下，4→中，5→上）

**示例**：本卦为天火同人（䷌，上乾下离）

- 下互卦：取2,3,4爻 → 阴,阳,阳 → 巽（☴）
- 上互卦：取3,4,5爻 → 阳,阳,阳 → 乾（☰）

**算法伪代码**：

```
# 本卦六爻: yao[0..5]，yao[0]为初爻(最下)，yao[5]为上爻(最上)
# 爻值: 1=阳爻, 0=阴爻

shang_hu_yao = [yao[2], yao[3], yao[4]] # 三、四、五爻 → 上互卦
```

### 2.3.2 本卦到变卦

**规则**：动爻所在位置的爻阴阳变化，其余五爻不变。

- 阳爻（1）变阴爻（0）
- 阴爻（0）变阳爻（1）
- 所在卦（上卦或下卦）整体改变

**示例**：本卦天火同人（䷌），动爻=2（二爻动）
- 原二爻为阴，变为阳
- 下卦由离（阳阴阴→101）变为乾（111），上卦不变
- 变卦：乾为天（䷀）

### 2.3.3 体卦与用卦

**规则**：
- 动爻在上卦 → 上卦为**用卦**，下卦为**体卦**
- 动爻在下卦 → 下卦为**用卦**，上卦为**体卦**
- 动爻数为6（上爻）→ 用卦为上卦
- 动爻数为1-3 → 用卦为下卦
- 动爻数为4-6 → 用卦为上卦

**体用含义**：
- **体卦**：代表问卦者自身，主体，静态方
- **用卦**：代表所问之事、对方、外部环境
- **体用生克**是断卦的核心依据

## 2.7 经典占卜案例

### 2.7.1 案例一：老人有忧色占（邵康节）

**出处**：《梅花易数》原文

**时间**：某日卯时（约早上5-7点）

**起卦**：邵雍见一老人面带忧色从东南方向来，便以人物方位起卦。
- 老人属乾卦（乾为父、为老人）→ 上卦为乾☰（先天数1）
- 东南方为巽☴方位（先天数5）→ 下卦为巽
- 乾1 + 巽5 + 卯时4 = 10，10 mod 6 = 4 → 第四爻动

**卦象推导**：
- **本卦**：天风姤 ䷫（上乾下巽）
- **互卦**：乾为天 ䷀（由姤卦的二三四爻和三四五爻推得）
  - 二三四爻：阳,阳,阳 → 乾
  - 三四五爻：阳,阳,阳 → 乾
- **变卦**：第四爻动（阳变阴），上卦乾变为巽 → 风为巽 ䷸
- **体用**：动爻在第四爻（上卦），上卦乾为**用卦**，下卦巽为**体卦**
- 用卦乾金克体卦巽木 → **用克体**，凶

**断卦**：邵雍断此老人五日内有灾。巽为股，乾克巽，防腿部受伤。后果应验，老人第五日赴宴时因鱼骨鲠喉而亡。

**教学要点**：此例展示"用克体"为凶，兼用外应（忧色）佐证。

# 第三部分：农历与节气

## 3.1 农历转换规则

### 3.1.1 农历基础知识

农历是阴阳合历：
- **阴历部分**：以月相变化周期（朔望月约29.53天）为每月长度
- **阳历部分**：以二十四节气调节太阳年
- **闰月**：19年7闰，使农历年与回归年（约365.2422天）保持一致

**农历月份**：
- 大月30天，小月29天
- 以朔日（日月合朔）为每月初一
- 以包含雨水的月份为正月

### 3.1.2 公历到农历转换算法概要

完整的公历转农历算法非常复杂，需要：
1. 精确的朔望月计算（日月合朔时刻）
2. 二十四节气精确时刻计算
3. 闰月判定规则

**简化实现方案**：
- 使用查表法，存储1900-2100年共200年的农历数据
- 每年数据包含：各月大小（29/30天）、闰月位置（0表示无闰月）、正月初一对应的公历日期
- 这种方案精度高，适合小程序使用

**核心数据结构**：
```
# 每年一条记录
lunar_info[year] = {
    "year": 2024,
    "first_day": (1, 1),      # 正月初一对应公历(月, 日)
    "month_days": [30,29,30,29,...], # 每月天数（含闰月）
    "leap_month": 0,           # 闰月位置，0表示无闰月
    "days_count": 354          # 该农历年总天数
}
```

### 3.1.3 公历日期转农历日期算法步骤

```
1. 计算目标公历日期距离农历年正月初一的天数差
2. 根据天数差和每月天数，累减确定农历月、日
3. 如果是闰月之后的月份，月份数字需要调整
4. 返回：(农历年, 农历月, 农历日, 是否闰月)
```

## 3.3 真太阳时

### 3.3.1 真太阳时概念

真太阳时是以太阳在天空中的实际位置来确定的时间，区别于人工制定的标准时间（如北京时间）。

- **平太阳时**：以假想的平均太阳视运动为基准的时间，即钟表时间
- **真太阳时**：以真实太阳视运动为基准的时间，考虑了地球轨道椭圆率和黄赤交角的影响

八字排盘需要使用**真太阳时**（至少矫正到地方平太阳时），因为时辰的确定基于太阳位置。

### 3.3.2 真太阳时换算方法

**基本换算公式**：
```
地方平太阳时 = 标准时间 + (本地经度 - 标准时间经度) × 4分钟
真太阳时 = 地方平太阳时 + 时差(均时差)
```

其中：
- 北京时间以东经120°为标准经度
- 经度差每1度对应4分钟时差
- 均时差（Equation of Time）在一年中约在-14分钟到+16分钟之间变化

**简化换算**（八字排盘一般使用地方时即可）：
```
地方时 = 北京时间 + (当地经度 - 120) × 4分钟
```

| 13:00 - 14:59 | 未时 |
| 15:00 - 16:59 | 申时 |
| 17:00 - 18:59 | 酉时 |
| 19:00 - 20:59 | 戌时 |
| 21:00 - 22:59 | 亥时 |

**算法**：
```
# 输入：标准时间(hour, minute)，当地经度(longitude)
# 输出：时辰地支索引(0=子,1=丑,...,11=亥)

offset = (longitude - 120) * 4  # 分钟差
local_minutes = hour * 60 + minute + offset
if local_minutes < 0:
    local_minutes += 1440  # 加一天
if local_minutes >= 1440:
    local_minutes -= 1440  # 减一天

shichen_index = (local_minutes + 60) // 120 % 12
# 加60分钟是因为子时从23:00开始，第一个120分钟桶是23:00-00:59
```
