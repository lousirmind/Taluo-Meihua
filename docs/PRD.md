## 1. 产品概述

### 1.1 产品定位与价值主张

"灵犀天机"是一款面向 Android 用户的严肃占卜工具，将传统命理测算（八字、梅花易数）与现代塔罗占卜相结合，并以 AI（DeepSeek API）提供自然语言解读。

产品同时提供四大功能模块：
- **融合占卜**：以梅花易数定势，级联映射塔罗牌阵，实现"宏观趋势 + 微观细节"的统一解读
- **梅花易数**：传统梅花独立占卜
- **塔罗占卜**：传统韦特塔罗 3 张牌占卜
- **八字命理**：完整四柱排盘 + 大运流年分析

**核心原则：**
- 严肃占卜定位，提供真实可追溯的命理计算过程
- 算法透明，排盘/起卦/抽牌过程对用户完全可见
- 使用 DeepSeek API 生成自然语言解读
- 无网时提示用户需联网
- 用户数据本地化存储，保护隐私

### 1.2 目标用户画像

**用户 A — 命理爱好者**
- 年龄：22-45 岁
- 特征：对八字、梅花易数有基础了解，希望获得专业准确的排盘工具
- 痛点：现有工具界面复杂、算法不透明
- 使用频次：高频（每周数次）

**用户 B — 占卜探索者**
- 年龄：20-40 岁
- 特征：对塔罗占卜感兴趣，也尝试过中国传统占卜方式
- 痛点：找不到将中西占卜体系统一的应用
- 使用频次：中频（每月数次）

**用户 C — 严肃求测者**
- 年龄：25-50 岁
- 特征：遇到重大决策时希望通过占卜获得参考
- 痛点：需要比娱乐类应用更深入的体系化解读
- 使用频次：低频但单次使用深度高

### 1.3 核心差异化特性

1. **中西合璧**：梅花易数与塔罗融合占卜，两种体系在统一逻辑下互为印证
2. **四大模块合一**：融合/梅花/塔罗/八字 四个功能集成在一个 App 中
3. **AI 深度解读**：DeepSeek API 驱动的自然语言解读，基于结构化卦象+牌面数据
4. **全流程可追溯**：每一步计算过程对用户可见（梅花取数→卦象推导、八字四柱推算等）
5. **算法驱动**：所有命理计算为确定性算法，非随机生成

### 1.4 产品名称

沿用品牌名"灵犀天机"，与参考微信小程序统一。

## 3. 融合占卜核心逻辑

### 3.1 级联映射架构

```
用户输入（3个数字 / 随机）
        │
        ▼
   ┌─────────────┐
   │  梅花起卦    │ ← 计算上卦、下卦、动爻
   └──────┬──────┘
          │
   ┌──────┴──────┐
   ▼              ▼
 本卦/互卦/变卦   体用生克
   │              │
   ▼              ▼
 决定塔罗牌阵     决定正逆位
  & 牌组选择      & 大阿卡纳/小阿卡纳
   │              │
   └──────┬──────┘
          ▼
    ┌──────────┐
    │  LLM解读  │ ← 结构化数据发送至 DeepSeek API
    └──────────┘
```

### 3.2 八卦五行 → 塔罗牌组映射规则

| 体卦/用卦五行 | 映射塔罗牌组 | 对应特征 |
|-------------|------------|---------|
| 火（乾、离） | 权杖（Wands） | 行动、意志、事业 |
| 土（坤、艮） | 星币（Pentacles） | 物质、财运、健康 |
| 木（震、巽） | 宝剑（Swords） | 思维、决策、冲突 |
| 水（坎、兑） | 圣杯（Cups） | 情感、关系、直觉 |
| 金（乾、兑） | 融入火/水 | 视具体卦象而定 |

### 3.3 体用生克 → 牌组与基调

| 生克关系 | 吉凶 | 塔罗映射 |
|---------|------|---------|
| 用生体 | 大吉 | 权杖牌组为主，正位为主，积极进取 |
| 比和 | 吉 | 圣杯+星币混合，和谐稳定 |
| 体克用 | 小吉 | 宝剑为主，需用智慧克服困难 |
| 体生用 | 小凶 | 星币为主，有付出才有回报 |
| 用克体 | 大凶 | 大阿卡纳为主，人生课题/重大警示 |

### 3.4 塔罗牌阵：三牌阵（过去/现在/未来）

三张牌逐张翻牌展示：

| 位置 | 含义 | 聚焦点 |
|------|------|--------|
| 位置1（左） | 过去背景 | 问题的起因和背景能量 |
| 位置2（中） | 当前形势 | 当下的核心状态 |
| 位置3（右） | 未来趋势 | 发展走向和结果提示 |

动爻位置（1-6）决定哪一个位置获得"双重放大解读"：
- 动爻 1-2 → 位置1（过去）重点解读
- 动爻 3-4 → 位置2（现在）重点解读
- 动爻 5-6 → 位置3（未来）重点解读

## 6. 数据模型

```
DivinationType: "fusion" | "meihua" | "tarot" | "bazi"
```

### 6.2 梅花易数数据模型

参考 `docs（参考）/reference-data.md` 中定义的标准数据结构，包含：

```dart
class MeihuaInput {
  final String method;  // "number" | "time"
  final int? number1;
  final int? number2;
  final int? number3;
  final DateTime? divinationTime;
}

class MeihuaResult {
  final Hexagram benGua;
  final Hexagram huGua;
  final Hexagram bianGua;
  final MovingYao movingYao;
  final TiYongAnalysis tiYong;
}

class Hexagram {
  final String name;
  final int sequence;       // 1-64
  final Trigram upper;
  final Trigram lower;
  final List<Line> lines;   // 6条爻
  final String guaCi;
  final String guaCiTranslation;
}

class Trigram {
  final String name;       // 乾坤兑离震巽坎艮
  final String element;    // 金木水火土
  final String symbol;     // ☰☱☲☳☴☵☶☷
  final String nature;     // 天泽火雷风水山地
}

class Line {
  final int position;     // 1-6
  final bool isYang;      // true=阳, false=阴
}
```

### 6.3 塔罗牌数据模型

```dart
class TarotCard {
  final int id;            // 1-78
  final String name;       // 牌名 eg. "愚者"
  final String nameEn;     // 英文名 eg. "The Fool"
```

## 7. 非功能性需求

### 7.1 性能要求

| 指标 | 要求 |
|------|------|
| App 首屏加载 | < 3 秒 |
| 梅花易数起卦计算 | < 500ms |
| 八字排盘计算 | < 2 秒 |
| 页面切换 | < 300ms |
| 历史记录列表加载 | < 1 秒（200 条以内） |
| DeepSeek API 解读 | < 15 秒，超时提示重试 |
| 翻牌动画 | 60fps 流畅 |

### 7.2 兼容性要求

| 维度 | 要求 |
|------|------|
| Android 版本 | Android 8.0（API 26）以上 |
| 屏幕适配 | 常规手机竖屏 |
| 网络 | 需联网才能使用 LLM 解读功能 |
| 字体 | 需支持八卦符号显示 |

### 7.3 可靠性要求

| 场景 | 处理策略 |
|------|---------|
| DeepSeek API 超时 | 15 秒超时，提示重试 |
| 网络断开 | 核心算法展示结果，解读区提示"需联网" |
| 输入不合法 | 前端校验 + 中文错误提示 |
| 存储空间不足 | 提示清理历史记录 |

### 7.4 安全性要求

- API Key 使用加密存储（flutter_secure_storage）
- 数据全部本地存储，不上传服务器
- 不建立账号体系
- 不收集任何用户个人信息

## 10. 开发优先级

1. 塔罗牌义库 JSON（78 张牌结构化数据）

3. 翻牌动画组件

### Phase 3 — 融合占卜
1. 梅花 → 塔罗映射逻辑
2. 融合占卜 UI 串联
3. DeepSeek API 集成

### Phase 4 — 八字命理
1. 八字输入 UI
2. 排盘结果展示 + 推导过程
3. 大运时间线组件

### Phase 5 — 收尾
1. 历史记录模块
2. 设置页（API Key 配置）
3. 免责声明 + 联网提示
